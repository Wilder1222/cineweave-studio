# Style review

Use evidence from Candidate Observation IDs. Review a style package by dimension rather than by overall impression.

## Review dimensions

- medium and representation;
- atom invariants and forbidden traits;
- palette, contrast and material behavior;
- linework, shading or surface rendering;
- composition and cinematography when in scope;
- character identity preservation;
- scene/culture/costume coherence;
- performance and motion representation;
- temporal stability for video;
- reference contamination and rights.

Each failed dimension names one observed failure, one smallest repair variable and a stop condition. Do not change the CharacterSpec, SceneSpec or StylePackage parent in a review.

## Common failures

- style reference content leaks into subject, costume or background;
- a named style alias remains a vague token instead of descriptive atoms;
- visual style is correct but temporal rhythm is absent;
- comic linework drifts frame to frame;
- palette matches but representation/medium does not;
- style conversion changes face geometry or body proportions;
- a high-density hero style is used unchanged for video;
- mixed atoms conflict and are silently averaged;
- the candidate is attractive but fails the package's invariants.
