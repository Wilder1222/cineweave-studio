# Prompt review and minimal repair

## Review dimensions

Evaluate the generated candidate against the prompt, not against unspecified taste:

- primary target and attention order;
- subject structure or identity;
- state, action and contact;
- composition, scale and depth;
- physical light direction and shadow coherence;
- material differentiation;
- style/medium fit;
- delivery constraints;
- reference leakage and rights status.

Record evidence from an actual observation. A prompt cannot be marked successful before media exists.

## Single-variable repair

1. Name one observed failure.
2. Assign it to one owner path.
3. Preserve every passing dimension.
4. Change one path only.
5. State a visible target and acceptance checks.
6. Stop when those checks pass; do not re-randomize the entire image.

Examples:

- eye shape drift → Character repair, not a global prompt rewrite;
- wrong doorway position → Scene repair;
- weak focal hierarchy → Director composition repair;
- physical source is correct but glow treatment is excessive → Style light grammar repair;
- prompt repeats incompatible focal lengths → Prompt repair.

Avoid “make it more beautiful/cinematic.” Replace it with an observable correction such as “reduce the eye's vertical opening while preserving eye spacing, iris direction, face shape, light and framing.”
