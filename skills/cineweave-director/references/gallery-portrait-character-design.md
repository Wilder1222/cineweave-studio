# Portrait character-design gallery

Use this category for identity, adornment, silhouette, palette and close-up character-state references. The bundled case is a user upload with unverified rights; it is suitable for local analysis only until permission is confirmed.

## Cases

### `portrait-character-design-dark-fantasy-001`

- Metadata: [`atlas/portrait-character-design/dark-fantasy-portrait-user-upload.json`](atlas/portrait-character-design/dark-fantasy-portrait-user-upload.json)
- Asset: [`atlas/portrait-character-design/dark-fantasy-portrait-user-upload.png`](atlas/portrait-character-design/dark-fantasy-portrait-user-upload.png)
- Source: `user_upload`; rights status `unverified`; do not redistribute or publish without confirmation.
- Strong roles: `identity`, `style`, `palette`, `pose` and `adornment` evidence for a close portrait.
- Conditional roles: `lighting` and `material`; use only for broad relationships because the rendering is painterly.
- Weak roles: `camera`, `environment`, wide spatial geography and live-action photographic realism.
- Pair with: an authorized photographic portrait for facial proportions, skin and lens behavior; a separate lighting reference for key/fill/rim direction.
- Preserve: hair silhouette, green eye accent, freckles, crescent forehead ornament, layered necklaces and dark-warm palette relationships.
- Borrow: frontal close-up crop, hand-to-lips gesture and restrained dark fantasy adornment logic.
- Exclude: exact identity when a new character is intended, painterly marks as photographic evidence, original signature/background and unmotivated accessory duplication.

For a portrait Prompt, decompose the case into identity, appearance, performance, capture, lighting, materials and palette before transferring it. The case is strongest for identity/adornment/gesture/palette; treat any 85mm, window-light, skin-pore or film-grain description as a separate photographic style hypothesis unless the supplied asset itself provides that evidence.

When using this case, bind it to one explicit role at a time and create a `reference-review` record before adding it to a production Prompt or RenderPlan.
