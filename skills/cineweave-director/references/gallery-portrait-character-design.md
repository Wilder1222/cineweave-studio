# Portrait character-design gallery

Use this category for identity, adornment, silhouette, palette and close-up
character-state references supplied by the user at runtime.

## Runtime review pattern

- Record source type, attribution, consent and publication status before reuse.
- Score identity, appearance, performance, capture, lighting, material, palette
  and environment authority separately.
- Treat painterly or generated marks as weak evidence for real lens behavior,
  skin response and physical lighting.
- Pair a stylized portrait with separately authorized identity, body, lighting
  or material evidence when those dimensions matter.
- Preserve only declared visible features; exclude signatures, watermarks,
  source identity and undifferentiated style copying unless explicitly allowed.

Bind one runtime Observation to one role at a time and create a
`reference-review` record before adding it to a production Prompt or RenderPlan.
