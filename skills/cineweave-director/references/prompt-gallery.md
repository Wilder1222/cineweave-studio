# Prompt reference gallery index

Use this file as a small routing index for reference-image selection and style classification. It is not a full prompt dump. Read one category for a normal request and only 2–3 categories for a deliberate hybrid.

## Loading policy

1. Identify the requested purpose and semantic role before choosing a category.
2. Read the smallest matching category file, then read the case metadata before binding an asset.
3. Transfer observable mechanisms—crop, viewpoint, gesture, light direction, material response, palette and spatial hierarchy—not an artist name or an unbounded style label.
4. Preserve `sourceType`, `rightsStatus`, attribution and usage notes. A gallery case is not a World fact, Canon fact or tested generation result.
5. If no suitable bundled case exists, say so and request a user-supplied or rights-cleared reference rather than inventing one.

## Gallery size rule

The gallery should remain small and high-signal. Add a case only when it teaches a repeatable decision, has provenance and rights notes, and can be routed by purpose. Update this index and the category file together. Do not load or paste every case into a normal Prompt.
