# Migrate CineWeave Studio 2.0 to 2.2

V2.2 is additive at the contract layer. Existing valid 2.0 artifacts remain
immutable and may continue to be referenced by exact hash.

## Ownership changes

| V2.0 | V2.2 |
| --- | --- |
| Director owns PromptRecord and ImagePrompt | Prompt owns all general image-prompt assets |
| no dedicated story owner | Story owns premise, beats, script scenes and continuity |
| SceneState mixes broad light notes | SceneLightState records physical source state |
| Style light atoms are not a separate contract | StyleLightGrammar owns representational treatment |
| Director camera information is embedded in prompt/storyboard payloads | ShotSpec, ShotLightingPlan and TemporalSpec are explicit |

## Project update

1. Install or check out `v2.2.0`.
2. Keep existing 2.0 files unchanged.
3. Route new prompt versions to `$cineweave-prompt`; do not change their IDs only
   to reflect owner movement.
4. For new continuity-sensitive work, create exact Story, light, shot and time
   contracts as needed; they are not mandatory for unrelated bounded tasks.
5. Initialize the local runtime only when immutable persistence is desired.
6. Run `npm test` and `npm run validate` before publishing a plugin snapshot.

WorkflowPlan's specialist enum now includes Story and Prompt. Update old example
plans that declared Director as the producer of ImagePrompt. The artifact itself
does not need mutation; create a new WorkflowPlan version with corrected ownership.
