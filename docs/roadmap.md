# CineWeave Studio v2 roadmap

## Completed in V2

- CineWeave Studio product identity and `cineweave-studio` package metadata;
- optional `$cineweave` creative-intake and workflow-composition Skill;
- six independently callable Skills with explicit standalone/composed contracts;
- versioned `cineweave-contracts@2.0.0` package;
- explicit `WorkflowPlan` DAG for multi-Skill projects;
- portable Skill-bundle build and validation;
- V2 activation, workflow, semantic, ControlBench and release checks.
- zero-prompt character discovery, candidate comparison and user-led preference
  convergence under the existing V2 contract package.

## Next product increments

1. **Project runtime** — persist CreativeBrief, WorkflowPlan and artifact refs in
   CineWeave Web or approved creator storage.
2. **Provider adapters** — add optional adapter plugins backed by real capability
   probes, execution receipts and license records; keep provider code outside the
   core Skills.
3. **Reference library** — add provenance-aware visual, temporal and historical
   reference assets with human approval and rights metadata.
4. **Review runtime** — connect candidate observations to Character, Scene and
   Style review/repair contracts.
5. **Video interchange** — add explicit camera-path, timing and temporal review
   adapters without turning static style images into motion evidence.

Every addition must preserve standalone specialist use, explicit contracts,
provider neutrality, human approval and evidence-based claims.
